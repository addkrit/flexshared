# Flex Shared ของคุณเอง (แทนเว็บ botmarketing ที่บันทึกไม่ได้)

## ทำไมของเดิมบันทึกไม่ได้
หน้า `botmarketing.github.io/flexshared` ส่งข้อมูลไปเก็บที่ Google Apps Script ของเจ้าของเว็บ
ซึ่งตอนนี้ตอบกลับ **"การเข้าถึงถูกปฏิเสธ (403)"** กับทุกคน → ปุ่ม บันทึก / โหลดรายการ / อัปเดต / ลบ ใช้ไม่ได้
เราแก้เว็บของเขาไม่ได้ (เป็น GitHub ของคนอื่น อัปเดตล่าสุดปี 2022) และ Flex ที่เคยบันทึกไว้ในนั้นเรียกกลับมาไม่ได้
ทางแก้คือใช้ชุดนี้ ซึ่งเก็บข้อมูลใน **Google Sheet ของคุณเอง**

## ไฟล์ในโฟลเดอร์นี้
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | หน้าเว็บ LIFF (บันทึก / เปิดแก้ไข / อัปเดต / ส่ง / แชร์ / ดูตัวอย่าง / ลบ / ลิงก์แชร์ต่อ) |
| `config.js` | ใส่ LIFF_ID และ SCRIPT_URL (แก้ไฟล์นี้ไฟล์เดียว) |
| `Code.gs` | ตัวเก็บข้อมูล วางใน Apps Script ของ Google Sheet |

## บั๊กของเดิมที่แก้แล้ว
- ตัวเก็บข้อมูลถูกปิดสิทธิ์ → ใช้ Sheet ของคุณเอง
- ช่อง "ข้อความแสดงแทน" ว่าง → ส่งไม่ผ่าน (โค้ดเดิมตั้งค่า "FLEX MESSAGE" ไว้แต่ไม่ได้ใช้) → แก้แล้ว
- กด "ดู JSON" หลายรายการแล้วกด Update → อัปเดตทับหลายรายการพร้อมกัน → แก้แล้ว
- ปุ่มในรายการผูกคำสั่งซ้อนกันทุกครั้งที่บันทึก (กดลบ 1 ครั้งเด้งหลายรอบ) → แก้แล้ว
- ใครรู้ id ก็ลบ/แก้ Flex ของคนอื่นได้ → ตอนนี้ยืนยันตัวตนด้วย LINE ID token จริง
- Flex ยาวเกิน 50,000 ตัวอักษร (ขีดจำกัดต่อช่องของ Sheet) → แบ่งเก็บหลายช่องอัตโนมัติ
- ไม่มีข้อความ error (หมุนค้าง) → ตอนนี้บอกสาเหตุทุกครั้ง
- `{{sharedFlex}}` ถูกแทนด้วยลิงก์แชร์ต่อของรายการนั้นอัตโนมัติหลังบันทึก
- มีตัวบอกขนาด (bubble ≤ 30 KB, carousel ≤ 50 KB ตามขีดจำกัดของ LINE)

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ~15 นาที)

### 1) เอาไฟล์ขึ้นเว็บ (GitHub Pages ฟรี)
1. เข้า github.com (ล็อกอินบัญชีของคุณ) > **New repository** ชื่อ `flexshared` > Public > Create
2. กด **uploading an existing file** > ลาก `index.html` และ `config.js` ขึ้นไป > Commit
3. **Settings > Pages** > Source: *Deploy from a branch* > Branch: `main` / `(root)` > Save
4. รอ 1–2 นาที จะได้ที่อยู่ `https://<ชื่อบัญชี>.github.io/flexshared/` ← จดไว้ (ใช้ในข้อ 2)

### 2) สร้าง LIFF app (LINE Developers)
1. เข้า developers.line.biz/console > เลือก Provider (หรือสร้างใหม่)
2. **Create a new channel > LINE Login** (ประเภทแอป: Web app) > สร้าง
3. แท็บ **LIFF > Add**
   - Size: **Full**
   - Endpoint URL: ที่อยู่จากข้อ 1.4
   - Scopes: ติ๊ก **openid**, **profile**, **chat_message.write**
   - **shareTargetPicker: เปิด (On)**
4. กด Add → จะได้ **LIFF ID** (เช่น `2001234567-AbCdEfGh`) ← จดไว้
5. ถ้าจะให้คนอื่นกด "ลิงก์แชร์ต่อ" ได้ด้วย: เปลี่ยนสถานะช่องจาก *Developing* เป็น **Published**
   (ถ้ายังเป็น Developing จะใช้ได้แค่บัญชีแอดมินของช่อง)

### 3) สร้างที่เก็บข้อมูล (Google Sheet + Apps Script)
1. เปิด sheets.new > ตั้งชื่อ เช่น `Flex Shared DB`
2. เมนู **ส่วนขยาย > Apps Script** > ลบโค้ดที่มีอยู่ > วางทั้งไฟล์ `Code.gs`
3. แก้บรรทัด `const LIFF_ID = '...'` ใส่ LIFF ID จากข้อ 2.4 > กดบันทึก (ไอคอนแผ่นดิสก์)
4. เลือกฟังก์ชัน **setup** ด้านบน > กด **เรียกใช้ (Run)** > อนุญาตสิทธิ์ (บัญชี Google ของคุณ)
   - ถ้าขึ้น "Google ยังไม่ได้ยืนยันแอปนี้" → ขั้นสูง > ไปที่โปรเจกต์ (ไม่ปลอดภัย) — เป็นสคริปต์ของคุณเอง
5. **ทำให้ใช้งานได้ > การทำให้ใช้งานได้รายการใหม่** > ไอคอนเฟือง เลือก **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด ทำให้ใช้งานได้ > คัดลอก **URL ที่ลงท้าย `/exec`** ← จดไว้

### 4) ใส่ค่าแล้วอัปโหลดอีกครั้ง
1. เปิด `config.js` ใส่ `LIFF_ID` (ข้อ 2.4) และ `SCRIPT_URL` (ข้อ 3.5)
2. อัปโหลด `config.js` ทับใน GitHub (Add file > Upload files > Commit)

### 5) ใช้งาน
- เปิด `https://liff.line.me/<LIFF_ID>` ในแชท LINE (ส่งลิงก์ให้ตัวเองแล้วกด)
- วาง JSON (จาก Flex Simulator หรือจาก `flex\out\...\flex.json`) > ใส่ข้อความแสดงแทน > **บันทึก**
- ปุ่ม "ส่งในห้องแชทนี้" จะขึ้นเมื่อเปิดจากในห้องแชท LINE เท่านั้น

## แก้ปัญหา
| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| "ยังไม่ได้ตั้งค่า" | ยังไม่ได้ใส่ค่าใน `config.js` หรือยังไม่ได้อัปโหลดทับ |
| "ติดต่อ Apps Script ไม่ได้" | URL ผิด (ต้องลงท้าย `/exec`) หรือ Deploy ไม่ได้ตั้ง "ทุกคน" |
| "ยืนยันตัวตนไม่ผ่าน" | `LIFF_ID` ใน Code.gs ไม่ตรงกับ config.js หรือ token หมดอายุ → ปิดแล้วเปิดใหม่ |
| "LIFF ยังไม่ได้เปิดสิทธิ์ openid" | LINE Developers > LIFF > Scopes ติ๊ก openid |
| แชร์ไม่ได้ | เปิด shareTargetPicker ใน LIFF |
| แก้ Code.gs แล้วไม่เปลี่ยน | ทำให้ใช้งานได้ > **จัดการการทำให้ใช้งานได้** > แก้ไข (ดินสอ) > เวอร์ชัน: **ใหม่** > ทำให้ใช้งานได้ (URL เดิม) |

ข้อมูลทั้งหมดอยู่ในแท็บ `flex` ของ Google Sheet คุณ (คอลัมน์ F เป็นต้นไปคือ JSON ที่แบ่งเก็บ ขึ้นต้นด้วย `~` ห้ามแก้มือ)
